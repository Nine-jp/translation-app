### 1. プロジェクトの初期設定とファイル作成

- **目的**: 日本語-スペイン語翻訳Webアプリの基本構造を構築。
- **ファイル構成**:
    - `index.html`: メインのHTMLファイル
    - `app.js`: アプリケーションのロジック（フロントエンド）
    - `style.css`: カスタムCSS
    - `sw.js`: Service Worker（PWA対応）
    - `manifest.json`: PWAマニフェスト
    - `icons/`: アプリケーションアイコン（ダミーファイル作成）
    - `log.txt`: このログファイル

        const express = require('express');
        const axios = require('axios');
        const path = require('path');

        const app = express();
        const port = 3000;

        app.use(express.json());
        app.use(express.static(path.join(__dirname, 'public'))); // publicフォルダから静的ファイルを提供

        app.post('/api/translate', async (req, res) => {
            const { text, from, to } = req.body;
            const apiKey = process.env.GEMINI_API_KEY;
            // ... Gemini API呼び出しロジック ...

        app.listen(port, () => {
            console.log(`サーバーが http://localhost:${port} で起動しました`);
        });

    5.  フロントエンドファイル（`index.html`, `app.js` など）を `public/` ディレクトリに移動。

### 3. GitとGitHubへのプッシュ

- **目的**: プロジェクトのバージョン管理とGitHubでの共有。
- **手順**:
    1.  `git add .` で全ファイルをステージング。
    2.  `git commit -F commit_message.txt` でコミット（コミットメッセージは一時ファイルに保存）。
        - コミットメッセージ: `feat: Initial setup of translation app with backend proxy`
    3.  `.gitignore` を作成し、`.env` と `node_modules/` をバージョン管理から除外。
    4.  GitHubリポジトリ (`https://github.com/Nine-jp/translation-app.git`) をリモートに追加。
        ```bash
        git remote add origin https://github.com/Nine-jp/translation-app.git
        ```
    5.  ブランチ名を `main` に変更。
        ```bash
        git branch -M main
        ```
    6.  GitHubにプッシュ。
        ```bash
        git push -u origin main
        ```

### 4. Herokuへのデプロイ（進行中）

- **目的**: Webアプリをインターネット上で利用可能にする。
- **Herokuの特性**: バックエンド（Node.js）を含むアプリのデプロイに適している。アプリ名は世界中でユニークである必要がある。
- **手順（ユーザーが手動で実行する必要があるステップ）**:
    1.  Heroku CLIのインストール（手動で実行済み）。
    2.  Herokuにログイン。
        ```bash
        heroku login
        ```
    3.  Herokuアプリの作成（ユニークな名前で）。
        ```bash
        heroku create YOUR_UNIQUE_APP_NAME
        ```
    4.  `Procfile` を作成し、Herokuにアプリの起動方法を指示。
        ```
        web: node server.js
        ```
    5.  Herokuにプッシュしてデプロイ。
        ```bash
        git push heroku main
        ```
    6.  Herokuダッシュボードで環境変数 `GEMINI_API_KEY` を設定。
        - **KEY**: `GEMINI_API_KEY`
        - **VALUE**: `AIzaSyA89wALTf-kGL9Rbpwkabd2Zs5KH8cGJrI`
        - **注意**: `Access denied` エラーは、アプリ名がユニークでない場合に発生する可能性が高い。新しいユニークなアプリ名で再試行を推奨。
